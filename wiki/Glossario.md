# Glossário

| Termo | Significado |
|---|---|
| HMI | Interface Homem-Máquina, o painel digital usado pelo operador. |
| ESP32-S3 | Microcontrolador que lê o sensor e envia os dados. |
| MLX90614 | Sensor infravermelho de temperatura. |
| MQTT | Protocolo usado para enviar dados pela rede WiFi. |
| Broker | Servidor intermediário que distribui as mensagens MQTT. |
| WebSocket | Tecnologia que permite receber dados em tempo real no navegador. |
| Offset | Valor de correção aplicado ao sensor. |
| Receita | Conjunto de parâmetros para um tipo de massa. |
| Ciclo | Período completo de mistura. |
| Telemetria | Dados enviados automaticamente pelo sensor. |
| PWA | Progressive Web App, aplicativo web instalável. |
| Simulador | Modo de teste com dados fictícios. |
