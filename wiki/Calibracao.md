# Calibração

A calibração de campo permite corrigir pequenas diferenças entre a leitura do sensor e a temperatura real.

## Quando usar

- Quando houver um termômetro de referência.
- Quando a leitura no aplicativo não coincidir com a leitura real.

## Como calibrar

1. Abra o painel de Calibração de campo.
2. Digite a temperatura de referência.
3. O sistema calcula automaticamente o offset.
4. Se o valor estiver entre `-5°C` e `+5°C`, envie o offset.

## Limite

Se o offset for maior que `5°C` em módulo, o botão fica desabilitado e o sensor deve ser verificado.
