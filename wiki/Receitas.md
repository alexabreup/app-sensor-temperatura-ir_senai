# Receitas

A tela de Receitas é a biblioteca usada para gerenciar os parâmetros industriais de cada massa.

## O que é uma receita

Uma receita define:

- Tempo de mistura.
- Temperatura mínima.
- Temperatura máxima.
- Temperatura crítica.
- Quantidade de água.

## O que aparece na lista

- Nome e código da receita.
- Faixa de temperatura.
- Temperatura crítica.

## Ações disponíveis

- `Editar`: altera os dados da receita.
- `Baixar JSON`: exporta em formato `.json`.
- `Baixar TXT`: exporta em formato `.txt`.
- `Excluir`: remove a receita com confirmação.
- `CARREGAR` / `ATIVA`: define a receita ativa.

## Criar uma nova receita

1. Clique em `NOVA RECEITA`.
2. Preencha os campos do formulário.
3. Clique em `SALVAR`.

## Editar uma receita

1. Clique no botão de edição da receita desejada.
2. Ajuste os campos necessários.
3. Salve as mudanças.

## Importar receitas

Formatos aceitos:

- `.json`
- `.txt`

## Exportar receitas

Use a exportação para manter backups periódicos, pois os dados ficam salvos localmente no navegador.
